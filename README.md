# Level 3 - Task 1: Image Manipulation 🖼️

## Project Overview

This project is created as part of the Cognifyz Technologies Web Development Internship.

The task focuses on image manipulation using HTML, CSS and JavaScript.

## Features

### 1. Image Gallery
- Created a basic image gallery using CSS.
- Multiple thumbnail images are displayed.
- Clicking on a thumbnail enlarges and displays the selected image.

### 2. Automatic Image Slideshow
- Implemented an automatic image slideshow.
- Images transition automatically after a fixed interval.
- The slideshow uses JavaScript to change the displayed image.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Open the `index.html` file in a web browser.
2. Click on any thumbnail to view the selected image.
3. The main image automatically changes every few seconds.
